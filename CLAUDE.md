# Token Optimization

- **Always use caveman style** — fragments, no filler, exact code/commands
- **No trailing summaries** — user can read diffs
- **Code first, prose after** — explain via code comments, not narration
- **Skip verification for non-UI** — tests/types/tooling don't need browser preview
- **No "let me..." prefixes** — act directly
- **Skip redundant explanations** — don't repeat what code shows
- **Batch tool calls** — parallelize independent reads/writes
- **One link per reference** — no markdown anchor text spam
